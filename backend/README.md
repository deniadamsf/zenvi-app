# 🌐 Zenvi API & ERP Backend (Laravel)

RESTful API and Business Management Backend for **Zenvi Multi-Tenant SaaS Platform**.

## 🌟 Fitur Utama
- **Multi-Tenant & Multi-Cabang:** Isolasi data perusahaan & outlet (`company_id`, `branch_id`).
- **Antigravity Bill of Materials (BOM):** Pengurangan stok bahan baku otomatis di background.
- **Push Notification Service (FCM HTTP v1):** Pengiriman notifikasi real-time via Google Service Account.
- **Presensi GPS & Selfie:** Validasi koordinat dan foto presensi shift.
- **Reservasi & Public QR Menu:** Endpoint katalog digital dan reservasi meja online.
- **Membership & Promo Engine:** Perhitungan diskon dan poin member.
- **Employee Permission & Approval:** Alur persetujuan cuti/izin karyawan.
