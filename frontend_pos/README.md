# 📱 Zenvi POS (Frontend Flutter)

Aplikasi Point of Sale (POS) dan Operasional Bisnis multi-tenant berbasis Flutter dengan kemampuan offline-first, notifikasi FCM, dan manajemen shift.

## 🌟 Fitur Utama
- **Kasir (POS):** Input pesanan cepat, varian menu, diskon, multi-metode pembayaran, scan member, dan cetak struk thermal.
- **Manajemen Shift & Kas:** Validasi modal awal laci kas, petty cash, foto presensi selfie, verifikasi lokasi GPS, dan blind shift closing.
- **Manajemen Stok (BOM):** Pemotongan stok bahan otomatis per porsi, pelaporan wastage, dan notifikasi stok menipis.
- **Reservasi Meja:** Manajemen booking meja/jasa terintegrasi.
- **Membership & Promo:** Poin loyalitas dan diskon member otomatis.
- **Pusat Notifikasi (FCM):** Notifikasi push dan in-app secara real-time.
- **Izin Karyawan & Chat:** Pengajuan izin/cuti dan chat internal.

## 🚀 Menjalankan Aplikasi
```bash
# Install dependencies
flutter pub get

# Jalankan analisis kode
flutter analyze

# Jalankan di emulator / device
flutter run
```
